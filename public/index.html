      HOW IT WORKS

      score.exe

      _□X

      Every candidate region gets one number: value per millisecond. The agent looks at the biggest one next.

      score(r) = p · s · (1 + u) · a / t̂

      p
      saliency prior from the overview, 0–1. How likely is something here?
      s
      class severity weight. Exposed rebar 3.0, spalling 2.0, crack 1.5, corrosion 1.0, efflorescence 0.5.
      u
      segmenter entropy at the last level that saw the region, 0 if unseen. How unsure are we?
      a
      fraction of the region not yet seen at the target level. Don’t look twice.
      t̂
      predicted milliseconds for the planned ops, from the live p95. What does looking cost?

      five_rules.txt

      _□X
      1. Next gaze. Take the highest score. Ties go to the larger unseen share, then top-left first, so a run is deterministic.
      2. Escalate. Zoom one level finer on the same centre when entropy > τ (0.5) or the mask is under 64 px, down to L0.
      3. Verify. When a mask appears at a new level, re-segment and record the IoU. Under 0.5 means one more gaze, or a human for a critical class.
      4. Stop. When the best remaining score falls below λ = ε × (value so far ÷ cost so far), or any cap is hit.
      5. Governor. Runs before every step and may override the model, level or batch size. Every override writes a cause into the trace.
