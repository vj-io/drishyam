## Rebuilding a checkout

1. `uv sync --all-extras`.
2. Download v1's weights and check their sha256: README, "Run it".
3. Optional: the comparison segmenters (v2a, v2b, v2c) for the held-out reruns are on the
   [eval-models](https://github.com/vj-io/drishyam/releases/tag/eval-models) pre-release, with the commands to fetch
   and check them.
4. `make data` fetches CODEBRIM from Zenodo into `data/codebrim`. The synthetic splits are generated by the eval
   scripts.
5. Tests:
   - unit: `uv run pytest -q --ignore=tests/e2e`;
   - browser, against a local fake: `uv run --no-project --with playwright==1.63.0 python tests/e2e/test_ui_mock.py`;
   - browser, against the live site: `tests/e2e/test_ui_live.py https://d1xg58guluup8c.cloudfront.net`.

## Deploying

[aws.md](aws.md) has the stack, the commands and the smoke checks. Three things learned the hard way:

- Run `WAF_LOOP=1 scripts/aws.sh smoke` last: it trips the WAF rate limit, which blocks this IP's job starts for
  about 5 minutes.
- A CDK asset upload can hang for hours after a DNS failure. Run the deploy under a time limit and retry.
- Each deploy is recorded in [aws.md](aws.md). The docs that name the live build follow it, and the tests check them.

## Rules the work has kept

- **Data licences.**
  - CODEBRIM's licence bars sharing its images: they never go into the repository, the site, the film or a release.
  - The segmenters' weights are CC BY-NC 4.0, from dacl10k: they are release assets, never committed.
- **Privacy.** Photos that carry GPS or show people stay out of the repository. The two real-wall photos in
  `public/samples` are the cleaned copies.
- **Honest evaluation.**
  - Tune on the dev splits only.
  - Commit a measurement's rule in `results/dev/` before its run, and adopt only what the rule calls a gain.
  - Score each configuration once on the held-out sets, and disclose every earlier read.
  - Publish failures and negative results.
- **The human gate.** Only a person approves or rejects a critical finding, or checks an area by eye. No agent,
  planner or tool gets a path to either.
- **Commits.** Stage files by name; never `git add -A`.

## Not in the repository
